    How it works

    Scan it. Check it. Move it.

    1

    Scan

    We list every new file and guess its library home.

    move new downloads scan
    2

    Review

    See source → target for everything. Suspects are flagged.

    get move new downloads scan report
    3

    Fix

    Pick a better folder — the filenames rebuild themselves.

    update move new downloads scan
    4

    Confirm

    Files move in the background. Jellyfin rescans when done.

    confirm move new downloads scan

    API

    Talk to it however you like

    # Start a scan of your new media files
curl -X POST localhost:18328/scans \
  -H 'Content-Type: application/json' \
  -d '{"replaceExisting": true}'

# Poll until completed, then read the plan
curl localhost:18328/scans/current/progress
curl localhost:18328/scans/current/report

# Move the files
curl -X POST localhost:18328/scans/{scan_id}/confirm
    # List tools
curl -X POST localhost:18328/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

# Scan your new media files
curl -X POST localhost:18328/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call",
       "params":{"name":"move new downloads scan",
                 "arguments":{"replaceExisting":true}}}'

    Set UI_PANEL_PASSWORD to put the panel behind login, JELLYSORT_MCP_TOKEN to gate /mcp.

    Self-host

    Up in five minutes

    cp .env.example .env
# point these at your new media files + libraries
# DOWNLOAD_ROOTS / MOVIE_ROOTS / SERIES_ROOTS
docker compose up -d --build
curl localhost:18328/health

    Key settings

    DOWNLOAD_ROOTSWhere your new media files land
    MOVIE_ROOTS / SERIES_ROOTSLibraries, each with an optional ::description
    WEB_UI_ENABLEDServes the panel at / on the same port
    UI_PANEL_PASSWORDLogin for the panel (empty = open)
    ENABLE_JELLYFIN_INTEGRATIONAuto-rescan libraries after moves

    FAQ

    Fair questions

    Will it move my files without asking?

    No. Scanning only builds a plan. Files move when you confirm them.

    What if a file lands in the wrong show folder?

    Retarget it from the report — the server fixes the season folder and filename.

    My libraries are on different drives. Problem?

    No. Cross-drive copies stream through a .partial file so an interrupt never leaves half a file behind.

    Does it touch files still arriving?

    No. In-progress files are spotted by their on-disk markers and skipped.
